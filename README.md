# Reconnaissance App - Aplikasi Pengintaian

Aplikasi Reconnaissance adalah tools untuk pengintaian informasi (Information Gathering) dan penjelajahan data dengan fitur-fitur lengkap untuk analisis dan penelusuran informasi.

## 🎯 Fitur Utama

- **Domain Reconnaissance**
  - DNS Lookup
  - WHOIS Information
  - Subdomain Enumeration
  - SSL Certificate Analysis

- **IP & Network Analysis**
  - IP Geolocation
  - Port Scanning
  - Network Range Discovery
  - ASN Lookup

- **Web Application Scanning**
  - Directory Enumeration
  - Technology Detection
  - Crawling & Indexing
  - Metadata Extraction

- **Social Engineering Intelligence**
  - Email Discovery
  - Social Media Profile Search
  - Employee Information Gathering
  - Company Information Collection

- **Database & Search Engines**
  - Public Database Search
  - Search Engine Dorking
  - Leaked Data Check
  - Dark Web Monitoring

## 📦 Teknologi

- **Backend**: Python/Node.js
- **Database**: MongoDB/PostgreSQL
- **Frontend**: React/Vue.js
- **API**: RESTful API

## 🚀 Instalasi

```bash
# Clone repository
git clone https://github.com/drbolon7-pixel/Reconnaissance-App.git

# Install dependencies
cd Reconnaissance-App
npm install
# atau
pip install -r requirements.txt
```

## 📋 Requirements

- Node.js 14+ / Python 3.8+
- npm / pip
- Git

## 🔧 Konfigurasi

1. Buat file `.env`
2. Sesuaikan konfigurasi API keys dan database

## 📚 Dokumentasi

Lihat folder `docs/` untuk dokumentasi lengkap.
